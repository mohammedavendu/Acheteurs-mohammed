Questions fréquentes

Avant de vous inscrire

Est-ce que ça me coûte quelque chose?

Les alertes sont gratuites. Si on achète ensemble, la rétribution du courtier de l'acheteur est habituellement payée par le vendeur. Je vous explique tout par écrit avant de commencer.

Suis-je obligé de travailler avec vous?

Non. Les alertes sont sans engagement. Vous décidez ensuite si vous voulez que je vous représente pour l'achat.

Comment vais-je recevoir les propriétés?

Par courriel, avec les fiches complètes. Quand une propriété se démarque, je peux aussi vous écrire par texto ou vous appeler.

C'est mon premier achat. Pouvez-vous m'aider?

Oui. Je vous explique chaque étape, de l'offre d'achat jusqu'au notaire, ainsi que les programmes pour premiers acheteurs comme le CELIAPP et le RAP. Pour les montants auxquels vous avez droit, je vous oriente vers votre institution financière ou un courtier hypothécaire.

Je n'ai pas encore de préapprobation. Est-ce un problème?

Pas du tout. Je vous accompagne pour savoir combien vous pouvez être préqualifié, avec les spécialistes et courtiers hypothécaires avec qui je travaille. C'est fortement recommandé avant de faire une offre.

Comment me désabonner?

Cliquez sur le lien de désabonnement dans un courriel ou dites-le-moi simplement. C'est immédiat.
